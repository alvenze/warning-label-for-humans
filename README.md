One line of at most 160 characters: the safety warning label that should come printed on every human being. The program writes the line to /output/entry.txt; the bounty judge compares entries two at a time and keeps the funnier one. The label is written in flat manufacturer voice throughout: a WARNING header, a hazard statement about the embarrassing moment from 2011 that resurfaces uninvited at 3 a.m., and a closing disposition in which "recall" turns from memory into product recall, which is where the sting lands.

## Run it

```sh
python3 main.py
```
